# 실험 방법과 한계

## 연구 질문과 평가 단위

같은 에이전트의 반복 샘플링에서 정답 후보의 존재가 실제 최빈 답 선택과 기권 후 출력으로 이어지는지 평가합니다. 통계 단위는 **부모 과제**입니다. 같은 과제의 여러 롤아웃을 독립 과제처럼 세지 않습니다.

| 단계 | 부모 과제 | 반복 수 | 총 실행 | 생성 조건 |
| --- | ---: | ---: | ---: | --- |
| 개발 CyBench 하위 질문 | 15 | 50 | 750 | prompt v1, low-effort 추론 |
| 앞 25회 선택 분석 | 같은 15 | 25 | 375회 재사용 | 개발 로그의 prefix |
| 미사용 CyBench 하위 질문 | 11 | 20 | 220 | prompt v2, 추론 비활성화 |
| 외부 최종 플래그 | 35 | 20 | 700 | prompt v2, 추론 비활성화 |

외부 35개는 NYU CTF Bench 7개와 InterCode-CTF 28개입니다. CyBench 하위 질문과 외부 최종 플래그는 채점 대상이 달라 분모와 결과를 분리합니다. `미사용`은 본 연구의 정책 선택에서 사용하지 않았다는 의미입니다.

## 실행 환경과 도구

- 모델: IBM Granite 4.2 8B GGUF, Q4_K_M.
- 하드웨어·엔진: RTX 5070, llama.cpp b11026, 문맥 8,192토큰.
- 샘플링: temperature 1.0, top-p 0.95, 시드 `1101 × j`.
- 도구: `list_files`, `read_file`, `strings`, `hexdump`.
- 예산: 롤아웃당 최대 4회 도구 호출, 턴당 최대 1,024 생성 토큰, 도구 출력 건당 4,000자·누적 5,000자.
- 독립 실행: 매 롤아웃의 메시지 기록과 도구 상태를 초기화.

초기 문맥 초과 이후 누적 도구 출력 상한을 추가한 재실행 결과와 개발 K=25·의미 분석은 탐색적 분석으로 해석합니다. 개발과 K=20 평가는 프롬프트·추론 조건도 달라 반복 수 하나의 효과로 직접 비교하지 않습니다.

## 선택·채점·진단의 구분

1. **정규화 문자열 최빈 답**: NFKC, 대소문자·공백·주변 인용부호·마크다운 정리 후 문자열 빈도로 선택합니다. 의미 군집을 먼저 합쳐 선택하지 않습니다.
2. **개발 동률**: 가장 앞선 시드의 답을 선택합니다. K=25 진단 기권은 최빈 답의 절대 빈도가 15회 이상일 때 응답합니다.
3. **K=20 고정 정책**: 유일한 최빈 답이며 `최빈 답 빈도 / 유효 응답 수 >= 0.60`일 때 응답합니다. 동률·유효 응답 없음·기준 미달은 기권합니다.
4. **정답 별칭 기준**: 선택된 답을 사전에 등록한 별칭과 정규화 후 대조하는 주 분석입니다.
5. **Oracle Pass@K**: 고정 시드 순서의 앞 K개에서 정답이 한 번이라도 존재하는 부모 과제의 비율입니다. 조합식 추정량이 아니라 관찰된 prefix이며, 실제 선택기에 정답표를 제공하지 않습니다.
6. **사후 의미 진단**: 단일 주석자가 정답표와 공개 파일을 보고 만든 군집의 정오·지지율·경험적 엔트로피를 평가합니다. 모호 판정은 정답으로 세지 않으며 정오 구분 AUROC에서 제외합니다.

지지율의 분모가 중요합니다. 20회 중 11회가 무효이고 나머지 9회가 같은 오답이면 유효 답 지지율은 9/9=1.0입니다. 높은 지지율과 전체 실행의 신뢰성을 동일하게 해석하지 않습니다.

## 보고 지표

| 지표 | 분모·해석 |
| --- | --- |
| Oracle·최빈 답 정답 수 | 전체 부모 과제 수 N |
| 응답률 | 응답한 과제 / 전체 과제 |
| 응답 오류율 | 응답한 과제 중 오답 / 응답한 과제 |
| 무효 롤아웃 비율 | 유효 최종 답을 얻지 못한 실행 / 전체 실행 |
| 정답 추가 기권 | 임계값 적용 전 맞았지만 적용 후 기권한 과제 수 |

원 분석의 불확실성 구간은 과제 단위 부트스트랩을 사용했습니다. 공개 검증 도구는 핵심 정수의 재집계를 수행하며 해당 구간이나 의미 AUROC를 다시 계산하지 않습니다.

## 해석할 수 있는 범위

정답 생성·선택·기권에서의 손실이 실제 보존 로그에 존재한다는 관찰을 제공합니다. 단일 양자화 모델과 제한된 정적 과제의 결과이므로 모든 에이전트·모델·대화형 사이버보안 환경으로 일반화하지 않습니다. 공개 CTF 문제의 사전학습 중복 여부와 독립 사람의 의미 주석 일치도는 확인되지 않았습니다.

후속 경로 안내·검증기·구조화 인터페이스·다중 모델·대화형 실험은 이 공개본의 핵심 결과에 합치지 않았습니다. 원 논문의 주 질문과 조건을 유지하기 위한 범위 구분입니다.
