# 공개용 실행 기록

`rollout_answers.jsonl`은 보존된 실제 모델 실행의 투영입니다. 개발 750·미사용 220·외부 700개, 총 1,670개입니다. 개발 K=25는 같은 750개 중 각 과제의 앞 25개를 사용합니다.

- `cohorts.json`: 부모 ID, 출처, 시드, 기록된 prompt 버전과 선택 규칙.
- `rollout_answers.jsonl`: 정규화 답의 SHA-256 식별자, 기존 strict 정오와 개발 사후 의미 주석. 무효 응답은 답 식별자가 `null`입니다.
- `source_inputs.json`: 배포하지 않은 원시 입력의 파일 식별자·SHA-256·기록 수.

모델 원문·추론문·도구 반환·외부 최종 플래그를 포함하는 원시 로그가 아닙니다. 식별자와 라벨로 선택 결과를 재집계할 수 있으나, 라벨을 원문에서 독립적으로 재채점할 수는 없습니다. SHA-256은 답의 동일성을 위한 키이며 익명성을 보장하지 않습니다.
